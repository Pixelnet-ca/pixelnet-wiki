# Resources

Recognized sources from the retro modding community: the places PixelNet checks for cap lists, install guides and opinions on mods. All links open on the original site.

!!! tip "Before you start a mod"
    Check your console's **model and board revision** first, then read the maker's own guide. Most failed installs come from following a guide meant for another revision.

## Reference wikis

| Source | What you'll find |
|---|---|
| [Console5 Tech Wiki](https://wiki.console5.com/wiki/Console5_Tech_Wiki){ target=_blank } | Capacitor lists by board revision, common faults, schematics and service documents. The reference for recaps. |
| [ConsoleMods Wiki](https://consolemods.org/){ target=_blank } | Community wiki on mods, repairs and restoration: install guides, soldering basics, video signals, model differences. |
| [NESdev Wiki](https://www.nesdev.org/wiki/){ target=_blank } | Deep NES/Famicom hardware documentation (PPU, CIC, expansion audio). |
| [Sega Retro](https://segaretro.org/){ target=_blank } | Encyclopedia of every Sega console, model and board revision. |
| [SNES Central](https://snescentral.com/){ target=_blank } | SNES and Super Famicom hardware, revisions and accessories. |
| [RetroSix Wiki](https://retrosix.wiki/){ target=_blank } | Install guides for RetroSix mods (CleanScreen, CleanRGB, CleanPower…). |
| [Tim Worthington's guides](https://etim.net.au/){ target=_blank } | Install guides for the NESRGB, N64RGB, 2600RGB, GGTV and SMSFM. |
| [Hand Held Legend Docs](https://docs.handheldlegend.com/){ target=_blank } | Step-by-step guides for handheld screens, shells and batteries. |
