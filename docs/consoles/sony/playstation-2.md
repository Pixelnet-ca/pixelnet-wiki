*2000–2013* · Component video gives a great picture stock. Mods are mostly about loading games from a drive or SD card.

| Model | Note |
|---|---|
| **SCPH-3000x to 5000x** | Fat: internal HDD with network adapter |
| **SCPH-7000x to 9000x** | Slim |

## Games & storage

### Internal HDD / SSD (fat)

Hard drive or SSD in the network adapter bay: fast loading with OPL.

<div class="pn-rate" markdown>
<span class="pn-k">Community</span> <span class="pn-stars pn-r5">★★★★★</span> **Must-have** · Best OPL compatibility and speed on fat models.

<span class="pn-k">Install</span> <span class="pn-bar pn-d1">■□□□</span> **Easy** · Screwdriver (often a game bit), drop-in parts, no soldering.
</div>

### MX4SIO

SD card adapter that plugs into a memory card slot, for any model including the slim.

<div class="pn-rate" markdown>
<span class="pn-k">Community</span> <span class="pn-stars pn-r3">★★★☆☆</span> **Good, with caveats** · Convenient on any model, but lower compatibility than a hard drive: some games crash or stutter, and SD card choice matters.

<span class="pn-k">Install</span> <span class="pn-bar pn-d0">□□□□</span> **Plug and play** · No tools, nothing to open.
</div>

:material-power-plug: No install

### SD2PSX

Memory card emulator: hundreds of virtual memory cards on one SD card.

<div class="pn-rate" markdown>
<span class="pn-k">Community</span> <span class="pn-stars pn-r4">★★★★☆</span> **Recommended** · Great memory card replacement.

<span class="pn-k">Install</span> <span class="pn-bar pn-d0">□□□□</span> **Plug and play** · No tools, nothing to open.
</div>

:material-power-plug: No install

## Softmod & homebrew

### FreeMcBoot + OPL

Softmod on a memory card. Open PS2 Loader then launches games from a hard drive, USB or network.

<div class="pn-rate" markdown>
<span class="pn-k">Community</span> <span class="pn-stars pn-r5">★★★★★</span> **Must-have** · Free and the standard way in.

<span class="pn-k">Install</span> <span class="pn-bar pn-d0">□□□□</span> **Plug and play** · No tools, nothing to open.
</div>

## Region & frequency

### Modchip

Hardware chip for imports and backups, when a softmod isn't enough.

<div class="pn-rate" markdown>
<span class="pn-k">Community</span> <span class="pn-stars pn-r2">★★☆☆☆</span> **Situational** · Mostly unnecessary now that softmods exist; complex installs.

<span class="pn-k">Install</span> <span class="pn-bar pn-d4">■■■■</span> **Expert** · Desoldering large chips or lifting chip pins, board rework. Good desoldering tools needed.
</div>

## Maintenance & reliability

### Laser, fan and thermal paste

Laser service and fresh thermal paste keep the fat models running cool.
