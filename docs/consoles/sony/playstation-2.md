# PlayStation 2

*2000–2013* · Component video gives a great picture stock. Mods are mostly about loading games from a drive or SD card.

| Model | Note |
|---|---|
| **SCPH-3000x to 5000x** | Fat: internal HDD with network adapter |
| **SCPH-7000x to 9000x** | Slim |

**Legend:** :material-wrench: **PixelNet installs it** · :material-book-open-variant: **Guide** on this wiki · :material-power-plug: **No install** (cart, adapter or software)

## Games & storage

### Internal HDD / SSD (fat)

Hard drive or SSD in the network adapter bay: fast loading with OPL.

### MX4SIO

SD card adapter that plugs into a memory card slot, for any model including the slim.

:material-power-plug: No install

### SD2PSX

Memory card emulator: hundreds of virtual memory cards on one SD card.

:material-power-plug: No install

## Softmod & homebrew

### FreeMcBoot + OPL

Softmod on a memory card. Open PS2 Loader then launches games from a hard drive, USB or network.

:material-power-plug: No install

## Region & frequency

### Modchip

Hardware chip for imports and backups, when a softmod isn't enough.

## Maintenance & reliability

### Laser, fan and thermal paste

Laser service and fresh thermal paste keep the fat models running cool.
