## Jeux et stockage

### XStation

ODE qui remplace le lecteur : jeux sur microSD, chargement plus rapide. Pour les modèles jusqu'à PU-18 (SCPH-550x); pas les modèles plus récents ni la PSone.

<div class="pn-rate" markdown>
<span class="pn-k">Communauté</span> <span class="pn-stars pn-r5">★★★★★</span> **Incontournable** · Le meilleur ODE PS1 selon la communauté, avec une bonne compatibilité. Seulement pour les modèles jusqu'à PU-18 (SCPH-550x). Quelques problèmes d'audio CD rapportés dans le firmware.

<span class="pn-k">Installation</span> <span class="pn-bar pn-d3">■■■□</span> **Avancé** · Soudure fine sur de petits points, retrait de composants, coupe de pistes.
</div>

### PicoStation

ODE open source, alternative moins chère au XStation.

<div class="pn-rate" markdown>
<span class="pn-k">Communauté</span> <span class="pn-stars pn-r3">★★★☆☆</span> **Bon, avec réserves** · Pas cher et open source; le développement a été irrégulier et il est moins éprouvé que le XStation.

<span class="pn-k">Installation</span> <span class="pn-bar pn-d3">■■■□</span> **Avancé** · Soudure fine sur de petits points, retrait de composants, coupe de pistes.
</div>

### PSIO

Se branche dans le port parallèle à l'arrière (premiers modèles seulement). Le lecteur reste en place.

<div class="pn-rate" markdown>
<span class="pn-k">Communauté</span> <span class="pn-stars pn-r3">★★★☆☆</span> **Bon, avec réserves** · Garde le lecteur et va sur les modèles PU-20 que le XStation ne prend pas. Historique de firmware capricieux.

<span class="pn-k">Installation</span> <span class="pn-bar pn-d2">■■□□</span> **Intermédiaire** · Soudure de base : quelques fils ou composants traversants.
</div>
