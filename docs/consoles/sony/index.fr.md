# Sony

PlayStation, PlayStation 2 et PSP.

| Console | Années | |
|---|---|---|
| [**PlayStation**](playstation.md) | 1994–2006 | Le lecteur est le point faible. Un ODE le remplace et charge les jeux sur carte microSD. |
| [**PlayStation 2**](playstation-2.md) | 2000–2013 | Le câble composantes donne une belle image d'origine. Les mods servent surtout à charger les jeux sur disque dur ou carte SD. |
| [**PSP**](psp.md) | 2004–2014 | Une belle portable qu'on modifie surtout par logiciel. |
