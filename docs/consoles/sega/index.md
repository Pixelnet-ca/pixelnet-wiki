# Sega

From the Master System to the Dreamcast, plus the Game Gear.

| Console | Years | |
|---|---|---|
| [**Master System**](master-system.md) | 1986–1992 | The first model outputs RGB stock; the Master System II lost its A/V port. |
| [**Genesis / Mega Drive**](genesis.md) | 1988–1997 | Outputs RGB stock, but the Model 2 has jailbars and the audio varies by board. Also covers the Sega CD, 32X and Nomad. |
| [**Saturn**](saturn.md) | 1994–2000 | Outputs RGB stock. Mods focus on loading games from SD and playing every region. |
| [**Dreamcast**](dreamcast.md) | 1998–2001 | Outputs VGA (480p) stock. An ODE replaces the noisy drive, the most common failure. |
| [**Game Gear**](game-gear.md) | 1990–1997 | Almost every Game Gear needs a recap. A modern screen fixes the blurry, ghosting LCD. |
