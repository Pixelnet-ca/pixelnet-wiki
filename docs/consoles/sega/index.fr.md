# Sega

De la Master System à la Dreamcast, plus la Game Gear.

| Console | Années | |
|---|---|---|
| [**Master System**](master-system.md) | 1986–1992 | Le premier modèle sort le RGB d'origine; la Master System II a perdu son port A/V. |
| [**Genesis / Mega Drive**](genesis.md) | 1988–1997 | Sort le RGB d'origine, mais le modèle 2 a des jailbars et le son varie selon la carte. Couvre aussi le Sega CD, le 32X et la Nomad. |
| [**Saturn**](saturn.md) | 1994–2000 | Sort le RGB d'origine. Les mods visent le chargement sur carte SD et le jeu toutes régions. |
| [**Dreamcast**](dreamcast.md) | 1998–2001 | Sort le VGA (480p) d'origine. Un ODE remplace le lecteur bruyant, la panne la plus fréquente. |
| [**Game Gear**](game-gear.md) | 1990–1997 | Presque toutes les Game Gear ont besoin d'un recap. Un écran moderne règle l'écran flou qui laisse des traînées. |
