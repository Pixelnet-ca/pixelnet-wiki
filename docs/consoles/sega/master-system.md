# Master System

*1986–1992* · The first model outputs RGB stock; the Master System II lost its A/V port.

| Model | Note |
|---|---|
| **SMS1** | Has RGB on the A/V port |
| **SMS2** | RF only |

## Audio

### SMSFM

FM sound expansion for the SMS1 and SMS2: adds the Japanese FM sound chip (YM2413) for the richer soundtrack of supported games.

<div class="pn-rate" markdown>
<span class="pn-k">Community</span> <span class="pn-stars pn-r4">★★★★☆</span> **Recommended** · Well-regarded way to hear the FM soundtracks.
