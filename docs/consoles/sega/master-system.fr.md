# Master System

*1986–1992* · Le premier modèle sort le RGB d'origine; la Master System II a perdu son port A/V.

| Modèle | Note |
|---|---|
| **SMS1** | A le RGB sur le port A/V |
| **SMS2** | RF seulement |
