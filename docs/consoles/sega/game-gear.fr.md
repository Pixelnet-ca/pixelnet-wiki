## Entretien et fiabilité

### Recap (essentiel)

Les condensateurs coulent sur presque toutes les consoles : pas de son, écran sombre ou vide. Un recap la ramène.

<div class="pn-rate" markdown>
<span class="pn-k">Communauté</span> <span class="pn-stars pn-r5">★★★★★</span> **Incontournable** · Presque toutes les Game Gear en ont besoin. Petits condensateurs en surface.

<span class="pn-k">Installation</span> <span class="pn-bar pn-d3">■■■□</span> **Avancé** · Soudure fine sur de petits points, retrait de composants, coupe de pistes.
</div>
