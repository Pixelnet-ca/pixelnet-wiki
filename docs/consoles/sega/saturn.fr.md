# Saturn

*1994–2000* · Sort le RGB d'origine. Les mods visent le chargement sur carte SD et le jeu toutes régions.

| Modèle | Note |
|---|---|
| **Modèle 1** | Boutons ovales |
| **Modèle 2** | Boutons ronds |
