# Xbox (original)

*2001–2006* · A very moddable console. First thing to do: remove the leaking clock capacitor.

| Model | Note |
|---|---|
| **1.0 to 1.6** | Motherboard revisions; mods depend on them |

<div class="pn-rate" markdown>

### Modchip / TSOP flash

Hardware mod for a custom BIOS (e.g. OpenXenium, open source). TSOP flash works on revisions 1.0 to 1.5.

<div class="pn-rate" markdown>
<span class="pn-k">Community</span> <span class="pn-stars pn-r4">★★★★☆</span> **Recommended** · OpenXenium is a community favourite (several BIOS banks, web flashing). TSOP flash is cheaper on 1.0–1.5 boards.

<span class="pn-k">Install</span> <span class="pn-bar pn-d3">■■■□</span> **Advanced** · Fine soldering on small points, removing parts, cutting traces.
</div>

## Maintenance & reliability

### Clock capacitor removal (essential)

The clock capacitor leaks and eats the board. Remove it on every Xbox, modded or not.

<div class="pn-rate" markdown>
<span class="pn-k">Community</span> <span class="pn-stars pn-r5">★★★★★</span> **Must-have** · Do it on every Xbox before it leaks.

<span class="pn-k">Install</span> <span class="pn-bar pn-d2">■■□□</span> **Intermediate** · Basic soldering: a few wires or through-hole parts.
</div>
