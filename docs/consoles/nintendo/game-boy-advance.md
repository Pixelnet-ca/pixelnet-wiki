# Game Boy Advance / SP

*2001–2008* · The original GBA has no light at all. IPS kits make it one of the best retro handhelds.

| Model | Note |
|---|---|
| **AGB-001** | Game Boy Advance |
| **AGS-001** | GBA SP, frontlit |
| **AGS-101** | GBA SP, backlit |

**Legend:** :material-wrench: **PixelNet installs it** · :material-book-open-variant: **Guide** on this wiki · :material-power-plug: **No install** (cart, adapter or software)

## Screen

### IPS screen kit

Laminated backlit IPS with brightness and colour settings. Versions exist for the GBA and the SP.

## Audio

### Audio amp board

Fixes buzzing and weak audio with a new amplifier.

## Power & battery

### USB-C rechargeable battery

USB-C battery kit for the GBA; USB-C charge port for the SP.

## Shell & buttons

### Shell, buttons and glass lens

IPS-ready shells, coloured buttons and glass lens.
