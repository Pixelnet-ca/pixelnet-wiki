# Game Boy Advance / SP

*2001–2008* · The original GBA has no light at all. IPS kits make it one of the best retro handhelds.

| Model | Note |
|---|---|
| **AGB-001** | Game Boy Advance |
| **AGS-001** | GBA SP, frontlit |
| **AGS-101** | GBA SP, backlit |

## Screen

### Hispeedido V5 IPS kit

Laminated 3.0-inch IPS (720×480) with integer scaling and an on-screen menu, with a pre-cut shell and optional battery. A drop-in version with shell exists for the SP (no trimming).
