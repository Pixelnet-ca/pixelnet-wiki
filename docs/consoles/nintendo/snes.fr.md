# Super Nintendo / Super Famicom

*1990–1999* · Sort le RGB d'origine, mais les cartes 2 puces ont une image molle avec du ghosting. Le nettoyage vidéo et les mods de région sont les classiques.

| Modèle | Note |
|---|---|
| **SNS-001** | Originale (2 puces ou 1CHIP) |
| **SNS-101** | SNES Jr / Mini : pas de RGB d'origine |
| **SHVC-001** | Super Famicom (Japon) |

## Vidéo

### CleanRGB + EdgeBuster (RetroSix)

Refait le signal RGB et enlève le ghosting et les contours flous des pixels. Gain énorme sur les cartes 2 puces.

### SNES Edge-Enhancer

SNES 2 puces : récupère la netteté perdue dans le circuit vidéo, près de la qualité 1CHIP. Améliore le RGB, le S-Video et le composite. Un recap est fortement conseillé avant.

<div class="pn-rate" markdown>
<span class="pn-k">Communauté</span> <span class="pn-stars pn-r5">★★★★★</span> **Incontournable** · Les critiques (My Life in Gaming, RetroRGB) trouvent qu'il amène les 2 puces près de la netteté 1CHIP, en RGB, S-Video et composite. Souvent en rupture.

<span class="pn-k">Installation</span> <span class="pn-bar pn-d3">■■■□</span> **Avancé** · Soudure fine sur de petits points, retrait de composants, coupe de pistes.

### SNESRGB (bypass)

Amplificateur RGB bypass : RGB plus propre sur les consoles 1CHIP, et ramène le RGB sur la SNES Jr. Une version 2 puces se jumelle à l'Edge-Enhancer.

<div class="pn-rate" markdown>

## Région et fréquence

### SuperCIC

Remplace la puce de verrouillage : joue toutes les régions et change 50/60 Hz avec le bouton reset, avec un voyant.

<div class="pn-rate" markdown>
<span class="pn-k">Communauté</span> <span class="pn-stars pn-r4">★★★★☆</span> **Recommandé** · Le meilleur mod de région SNES, compatible avec tous les imports. Les installations ratées sont fréquentes : prends ton temps.

<span class="pn-k">Installation</span> <span class="pn-bar pn-d3">■■■□</span> **Avancé** · Soudure fine sur de petits points, retrait de composants, coupe de pistes.
</div>

### Fente de cartouche taillée

On enlève les languettes de plastique pour que les cartouches Super Famicom entrent dans une SNES nord-américaine.

<div class="pn-rate" markdown>
<span class="pn-k">Communauté</span> <span class="pn-stars pn-r4">★★★★☆</span> **Recommandé** · Gratuit et facile, mais permanent : les languettes ne reviennent pas.

<span class="pn-k">Installation</span> <span class="pn-bar pn-d1">■□□□</span> **Facile** · Tournevis (souvent une pointe spéciale), pièces prêtes à installer, sans soudure.
</div>
