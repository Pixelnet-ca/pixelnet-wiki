# Game Boy / Game Boy Pocket

*1989–1998* · L'écran vert original n'a pas de rétroéclairage. Un écran IPS rétroéclairé et une pile rechargeable changent tout.

| Modèle | Note |
|---|---|
| **DMG-01** | Game Boy original |
| **MGB-001** | Game Boy Pocket |

### Trousse d'écran IPS

Écran IPS rétroéclairé et lumineux, avec niveaux de luminosité et palettes de couleurs. Certaines trousses demandent un boîtier taillé ou neuf.

<div class="pn-rate" markdown>
<span class="pn-k">Communauté</span> <span class="pn-stars pn-r5">★★★★★</span> **Incontournable** · Le mod Game Boy le plus populaire. Les trousses laminées sont les favorites; certaines demandent un boîtier taillé ou prêt pour l'IPS.

<span class="pn-k">Installation</span> <span class="pn-bar pn-d1">■□□□</span> **Facile** · Tournevis (souvent une pointe spéciale), pièces prêtes à installer, sans soudure.

### Rétroéclairage + bivert

Méthode plus ancienne : un rétroéclairage derrière l'écran d'origine, avec une puce bivert pour retrouver le contraste.

<div class="pn-rate" markdown>
