# Nintendo

Home consoles and handhelds, from the NES to the Wii.

| Console | Years | |
|---|---|---|
| [**NES / Famicom**](nes.md) | 1983–1995 | Stock, the front-loader only has composite and RF: a soft, smeared picture. Video mods make the biggest difference. |
| [**Super Nintendo / Super Famicom**](snes.md) | 1990–1999 | Outputs RGB stock, but 2-chip boards have a soft, ghosty picture. Video cleanup and region mods are the classics. |
| [**Nintendo 64**](n64.md) | 1996–2002 | North American N64s have no RGB stock and a blurry picture. Digital HDMI or RGB mods transform it. |
| [**GameCube**](gamecube.md) | 2001–2007 | Excellent picture in 480p. Mods focus on HDMI and loading games from an SD card. |
| [**Wii**](wii.md) | 2006–2013 | Plays GameCube games too (RVL-001). Most Wii mods are software only. |
| [**Game Boy / Game Boy Pocket**](game-boy.md) | 1989–1998 | The original green screen has no backlight. A backlit IPS screen and a rechargeable battery change everything. |
| [**Game Boy Color**](game-boy-color.md) | 1998–2003 | Unlit colour screen that's hard to see. An IPS screen is the mod everyone wants. |
| [**Game Boy Advance / SP**](game-boy-advance.md) | 2001–2008 | The original GBA has no light at all. IPS kits make it one of the best retro handhelds. |
