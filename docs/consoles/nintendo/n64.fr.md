# Nintendo 64

*1996–2002* · Les N64 nord-américaines n'ont pas de RGB d'origine et l'image est floue. Les mods HDMI numérique ou RGB la transforment.

| Modèle | Note |
|---|---|
| **NUS-CPU-01 à -03** | Premières cartes : RGB plus facile |
| **NUS-CPU-04 et plus** | Demandent une carte RGB numérique |

**Légende :** :material-wrench: **Installé par PixelNet** · :material-book-open-variant: **Guide** sur ce wiki · :material-power-plug: **Sans installation** (cartouche, adaptateur ou logiciel) · :material-cart: **Acheter** à la source officielle

## Vidéo

### N64Digital (PixelFX)

Sortie HDMI numérique interne avec mise à l'échelle, de-blur et scanlines. La meilleure image N64.

[:material-cart: Acheter](https://www.pixelfx.co){ target=_blank }

### N64RGB

Prend le bus vidéo numérique et sort du RGB. Fonctionne sur toutes les révisions de carte.

:material-account-hard-hat: par [Tim Worthington](https://etim.net.au){ target=_blank } · [:material-cart: Acheter](https://etim.net.au/shop/shop.php){ target=_blank }

### N64 Advanced

Carte RGB numérique open source qui ajoute le de-blur et le doublement de lignes.

[:material-cart: Acheter](https://github.com/borti4938/n64adv2){ target=_blank }

### N64RGB Kit

Amplificateur RGB avec séparateur de synchro intégré pour les premières cartes (NUS-CPU-01 à -03). Fonctionne avec un câble SNES csync standard.

:material-account-hard-hat: par [Voultar](https://voultar.com/index.php?route=product/category&path=59){ target=_blank } · [:material-cart: Acheter](https://voultar.com/index.php?route=product/category&path=59){ target=_blank }

## Région et fréquence

### Fente de cartouche taillée

On enlève les languettes de la fente pour que les cartouches japonaises entrent dans une console nord-américaine (même verrouillage NTSC).

## Contrôles

### Remplacement du joystick

Remplace les joysticks usés et mous par de nouveaux modules (style GameCube ou à effet Hall).
