# Nintendo

Consoles de salon et portables, de la NES à la Wii.

| Console | Années | |
|---|---|---|
| [**NES / Famicom**](nes.md) | 1983–1995 | D'origine, la NES n'a que le composite et le RF : une image floue et baveuse. Les mods vidéo font la plus grosse différence. |
| [**Super Nintendo / Super Famicom**](snes.md) | 1990–1999 | Sort le RGB d'origine, mais les cartes 2 puces ont une image molle avec du ghosting. Le nettoyage vidéo et les mods de région sont les classiques. |
| [**Nintendo 64**](n64.md) | 1996–2002 | Les N64 nord-américaines n'ont pas de RGB d'origine et l'image est floue. Les mods HDMI numérique ou RGB la transforment. |
| [**GameCube**](gamecube.md) | 2001–2007 | Excellente image en 480p. Les mods visent le HDMI et le chargement des jeux sur carte SD. |
| [**Wii**](wii.md) | 2006–2013 | Joue aussi aux jeux GameCube (RVL-001). La plupart des mods Wii sont logiciels. |
| [**Game Boy / Game Boy Pocket**](game-boy.md) | 1989–1998 | L'écran vert original n'a pas de rétroéclairage. Un écran IPS rétroéclairé et une pile rechargeable changent tout. |
| [**Game Boy Color**](game-boy-color.md) | 1998–2003 | Écran couleur sans éclairage, difficile à voir. L'écran IPS est le mod que tout le monde veut. |
| [**Game Boy Advance / SP**](game-boy-advance.md) | 2001–2008 | La GBA originale n'a aucun éclairage. Les trousses IPS en font une des meilleures portables rétro. |
