# Nintendo 64

*1996–2002* · North American N64s have no RGB stock and a blurry picture. Digital HDMI or RGB mods transform it.

| Model | Note |
|---|---|
| **NUS-CPU-01 to -03** | Early boards: easier RGB |
| **NUS-CPU-04 and later** | Need a digital RGB board |

**Legend:** :material-wrench: **PixelNet installs it** · :material-book-open-variant: **Guide** on this wiki · :material-power-plug: **No install** (cart, adapter or software) · :material-cart: **Buy** from the official source

## Video

### N64Digital (PixelFX)

Internal digital HDMI output with scaling, de-blur and scanlines. The best N64 picture.

[:material-cart: Buy](https://www.pixelfx.co){ target=_blank }

### N64RGB

Takes the digital video bus and outputs RGB. Works on every board revision.

:material-account-hard-hat: by [Tim Worthington](https://etim.net.au){ target=_blank } · [:material-cart: Buy](https://etim.net.au/shop/shop.php){ target=_blank }

### N64 Advanced

Open-source digital RGB board that adds de-blur and line doubling.

[:material-cart: Buy](https://github.com/borti4938/n64adv2){ target=_blank }

### N64RGB Kit

RGB amplifier with built-in sync stripper for the early boards (NUS-CPU-01 to -03). Works with a standard SNES csync cable.

:material-account-hard-hat: by [Voultar](https://voultar.com/index.php?route=product/category&path=59){ target=_blank } · [:material-cart: Buy](https://voultar.com/index.php?route=product/category&path=59){ target=_blank }

## Games & storage

### EverDrive 64 / SummerCart64

Flash cartridges: games from an SD card, with save types handled automatically. SummerCart64 is open source.

[:material-cart: Buy](https://krikzz.com){ target=_blank } · :material-power-plug: No install

## Region & frequency

### Cartridge slot trim

Removes the slot tabs so Japanese carts fit a North American console (same NTSC lockout).

## Controls

### Joystick replacement

Replaces worn, loose controller sticks with new modules (GameCube-style or hall-effect).
