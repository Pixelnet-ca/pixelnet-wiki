# Game Boy / Game Boy Pocket

*1989–1998* · The original green screen has no backlight. A backlit IPS screen and a rechargeable battery change everything.

| Model | Note |
|---|---|
| **DMG-01** | Original Game Boy |
| **MGB-001** | Game Boy Pocket |

**Legend:** :material-wrench: **PixelNet installs it** · :material-book-open-variant: **Guide** on this wiki · :material-power-plug: **No install** (cart, adapter or software) · :material-cart: **Buy** from the official source

## Screen

### Hispeedido IPS kit

Laminated 3.1-inch IPS (Q5 / V5) with integer scaling, sold with a pre-cut shell and optional USB-C battery. Pocket kits too, with a colour-changing logo.

### IPS screen kit

Bright backlit IPS screen with brightness levels and colour palettes. Some kits need a trimmed or new shell.
