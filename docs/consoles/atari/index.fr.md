# Atari

De la 2600 à la Jaguar, plus la portable Lynx.

| Console | Années | |
|---|---|---|
| [**Atari 2600**](2600.md) | 1977–1992 | RF seulement. Un mod composite / S-Video est l'amélioration essentielle. |
| [**Atari 5200**](5200.md) | 1982–1984 | RF seulement, et les manettes sont son point faible. |
| [**Atari 7800**](7800.md) | 1986–1992 | Joue aussi aux jeux 2600. RF seulement d'origine. |
| [**Atari Lynx**](lynx.md) | 1989–1995 | Portable couleur à l'écran sombre. Les trousses d'écran modernes la font briller. |
| [**Atari Jaguar**](jaguar.md) | 1993–1996 | Sort le RGB d'origine. Les mods visent le homebrew et le chargement des jeux. |
