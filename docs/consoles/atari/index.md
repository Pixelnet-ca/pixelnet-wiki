# Atari

From the 2600 to the Jaguar, plus the Lynx handheld.

| Console | Years | |
|---|---|---|
| [**Atari 2600**](2600.md) | 1977–1992 | RF only. A composite / S-Video mod is the essential upgrade. |
| [**Atari 5200**](5200.md) | 1982–1984 | RF only, and the controllers are its weak point. |
| [**Atari 7800**](7800.md) | 1986–1992 | Plays 2600 games too. RF only stock. |
| [**Atari Lynx**](lynx.md) | 1989–1995 | Colour handheld with a dim screen. Modern screen kits make it shine. |
| [**Atari Jaguar**](jaguar.md) | 1993–1996 | Outputs RGB stock. Mods are about homebrew and loading games. |
