# Autres consoles

3DO, ColecoVision, Intellivision et Vectrex.

| Console | Années | |
|---|---|---|
| [**3DO**](3do.md) | 1993–1996 | Fabriquée par plusieurs compagnies (Panasonic, Goldstar, Sanyo). |
| [**ColecoVision**](colecovision.md) | 1982–1985 | RF seulement, avec un bloc d'alimentation qu'il vaut mieux remplacer. |
| [**Intellivision**](intellivision.md) | 1979–1990 | RF seulement. Un mod composite est la principale amélioration. |
| [**Vectrex**](vectrex.md) | 1982–1984 | Console avec écran vectoriel intégré. |

!!! tip "Tu veux faire installer un mod ?"
    PixelNet installe des mods et répare des consoles sur demande, même pour des mods absents de la boutique. Écris à [support@pixelnet.ca](mailto:support@pixelnet.ca) ou visite [pixelnet.ca](https://pixelnet.ca).
