# Other consoles

3DO, ColecoVision, Intellivision and Vectrex.

| Console | Years | |
|---|---|---|
| [**3DO**](3do.md) | 1993–1996 | Made by several companies (Panasonic, Goldstar, Sanyo). |
| [**ColecoVision**](colecovision.md) | 1982–1985 | RF only, with a power supply that's best replaced. |
| [**Intellivision**](intellivision.md) | 1979–1990 | RF only. A composite mod is the main upgrade. |
| [**Vectrex**](vectrex.md) | 1982–1984 | Console with a built-in vector screen. |
