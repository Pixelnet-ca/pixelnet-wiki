# PixelNet Edition

Des consoles entièrement remises à neuf et moddées, montées une à la fois à Trois-Rivières, au Québec. Chacune reçoit un numéro, un badge sur le boîtier et une carte de build dans la boîte. Cette page est le registre officiel : si tu as une PixelNet Edition, trouve ton numéro ci-dessous pour voir exactement ce qui a été fait.

!!! info "Comment vérifier ta console"
    Scanne le code QR de ta carte de build, ou repère le badge rouge **PIXELNET EDITION #000** sur le boîtier et trouve ce numéro ici.

    Retourne ensuite la console : le **numéro de série** dessous doit finir par les chiffres indiqués pour ton build. Chaque carte et autocollant intérieur est aussi signé à la main. Si le numéro ne correspond pas, ce n'est pas une vraie PixelNet Edition — écris-nous.
