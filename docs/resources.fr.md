# Ressources

Les sources reconnues de la communauté du modding rétro : là où PixelNet vérifie les listes de condensateurs, les guides d'installation et les avis sur les mods. Tous les liens s'ouvrent sur le site d'origine (souvent en anglais).

!!! tip "Avant de commencer un mod"
    Vérifie d'abord le **modèle et la révision de la carte** de ta console, puis lis le guide du concepteur. La plupart des installations ratées viennent d'un guide fait pour une autre révision.
